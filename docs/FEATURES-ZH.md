# 相比原版的功能变化

基准：OakRoller/3Danmu 原版 v1.2.0，提交 `ebbe757605135bace131651cc563c8a47cdf7a6a`（本地保存的最初上游快照）。目标：`1.3.9`。这里比较的是本次开发的起点与终点，并非声称比较了上游现在的最新版本。

| 范围 | 原版起点 | Kina v1.3.9 增加或改进 |
|---|---|---|
| 稍后再看 | 没有本次新增的列表管理入口 | 主页选中视频按 X，读取状态并确认添加/移除；个人中心浏览稍后再看；操作后刷新列表 |
| 搜索 | 视频搜索 | 增加 UP 主搜索、番剧搜索；UP 结果可进入资料与投稿页 |
| 个人中心 | 历史、收藏等分散入口 | 增加个人中心：我的投稿、播放历史、我的关注、我的粉丝、稍后再看 |
| UP 与社交 | 缺少本次新增页面与流程 | UP 资料、投稿列表、关注及二次确认取关；播放页查看 UP；关注和 UP 搜索支持四行窗口翻页及粉色选择提示 |
| 收藏夹浏览 | 以默认收藏夹为主 | 切换其他收藏夹，播放全部，顺序/随机/整夹循环队列；分页、失效条目和账号变化保护 |
| 点赞投币收藏 | 没有本次的完整互动菜单 | 播放页 X 打开互动，显示已有状态；点赞/取消、投币、收藏夹多选及提交确认 |
| 收藏选择操作 | 无此改版流程 | 每页 3 个收藏夹，上/L 上一页、下/R 下一页；触屏勾选，跨页保留；X 两次确认提交，B 返回；A 不再操作隐藏光标 |
| 跳转 | 已有进度条拖动 | L/R 或方向左右短按跳转 5 秒，长按连续跳转 |
| 倍速 | 没有本次倍速策略 | A 长按临时 2 倍速；设置记住 1/1.25/1.5/2 倍；音频采用时间伸缩保持音调 |
| 播放策略 | 原版播放行为 | 可关闭打开视频自动播放、记忆弹幕开关；播完暂停/自动连播/当前 P 循环；同稿件多 P、明确合集和收藏夹队列导航 |
| 播放中清晰度 | 已有 360P/480P 能力 | 播放设置内切换清晰度，重新取当前 P，恢复位置和暂停状态 |
| 截图 | 没有本次相册截图功能 | 播放页 Y 截图，保存到 3DS 相册 DCIM JPEG；下屏成功/失败提示并尝试播放提示音；最终版不向 Luma screenshots 回退 |
| 输入法 | 已有触屏拼音输入 | 待确认字母粉色加下划线，完成时先提交英文，单字候选上屏提示，v 按 u 查找 |
| 番剧/合集 | 没有本次独立浏览与导航流程 | 番剧搜索/选集及明确合集导航；错误保持在相关页面并显示原因，不绕过访问限制 |
| 安装身份 | 原版应用与数据目录 | 独立名称 3Danmu Kina、固定 Title ID `000400000F8DA100`、独立 `sdmc:/3ds/3danmu-kina/` 数据目录，与原版隔离 |

原版已经有的功能不能算作本次新增：推荐/热门、视频搜索、扫码登录、拼音键盘、在线视频、MVD/软解、360P/480P、弹幕及发弹幕、字幕、评论、分 P 选择、观看历史上报、裸眼 3D、画面比例、进度条拖动、封面、设置持久化与调试台。

## 修复与最终范围

- 改进播放设置切换、历史恢复、分 P/合集导航和收藏队列分页；处理空条目、删除视频、请求频率与缓存等情况。
- 相册截图编码使用标准 Huffman，减少临时内存、增加线程栈，细分编码/内存/目录/写入/关闭错误反馈。
- 最终个人中心不提供动态、消息入口；它们不能列为已完成功能。
- 不提供批量下载，不绕过付费、会员、地区或 DRM 限制。

## 验证边界

测试方法及需要设备确认的范围见 `docs/VERIFICATION.md`。
旧对话曾记录用户确认某版截图可进入真机相册；这不等于最终版本的提示音、内存改进、触屏布局、Old 3DS 性能、真实网络与在线写入全部通过。最终版本这些行为仍为 UNVERIFIED，需在对应设备和登录账号上实测。
