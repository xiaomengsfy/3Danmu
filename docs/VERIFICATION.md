# 测试与验证边界

功能版本：1.3.9。

在仓库根目录运行 `CC=gcc bash tools/test-host.sh` 执行主机回归。输出写入 Git 忽略的 `build/host-tests/`，不要把编译产物或本地测试日志加入源码发布。

主机用例覆盖 API 响应解析、历史记录普通视频/番剧分类、个人中心两列导航、收藏夹方向键选择/翻页/上屏信息、收藏队列及其他核心逻辑。测试使用模拟输入与传输边界，不访问真实账号。

主机测试不能替代 ARM 交叉构建、安装、真机画面、按键触摸、MVD 解码、音频、相册和真实在线接口验证。设备及账号行为必须在对应环境独立确认，未经实测不得标为通过。

构建方法见 BUILD-ZH.md，设备测试参考根目录 TESTING.md。SOURCE-MANIFEST.json 记录发布文件大小和 SHA-256，排除清单自身、Git 元数据与构建输出。
